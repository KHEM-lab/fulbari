# Fulbari Educational Academy Website

## Overview
This site is a single-page school website built with HTML, CSS, and JavaScript.
It is hosted from `index.html` in this folder and uses local assets in `images/`, `assets/css/`, and `assets/js/`.

## File structure
- `index.html` — main site page
- `assets/css/styles.css` — site styling
- `assets/js/script.js` — gallery lightbox behavior
- `images/` — school photos used in the gallery

## How to manage the site
1. Update the page content inside `index.html`.
2. Update visual styling in `assets/css/styles.css`.
3. Update interactive behavior in `assets/js/script.js`.
4. Add or replace photos in `images/`.

## Local preview
- Place this folder under your XAMPP `htdocs` directory.
- Open the site in a browser at `http://localhost/fulbari-academy/`.

## Notes
- Keep the gallery image names and paths consistent.
- Use the contact form `action` field to connect with a Formspree or another backend service.
